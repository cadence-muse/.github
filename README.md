# Cadence organization profile

This repository contains the public profile for the [Cadence organization](https://github.com/cadence-muse),
a repertoire manager for musical bands.

## 📝 Editing the profile

Update [`profile/README.md`](profile/README.md) to change the content displayed on the organization page.
Keep application screenshots in a repository-owned `profile/assets/` directory and reference them with relative paths.
